# Netflix Movies and TV Shows Analysis Dashboard

##  Project Overview
This project focuses on analyzing Netflix Movies and TV Shows data using **Power BI**. The dashboard provides insights into content distribution, genres, ratings, release years, and countries.

The main objective is to understand Netflix's content trends through interactive data visualizations.

##  Tools Used
- **Power BI** – Dashboard creation and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Creating measures and calculations

##  Key Performance Indicators (KPIs)
- **Total Titles:** 8,803
- **Total Ratings:** 19
- **Total Genres:** 515
- **Earliest Release Year:** 1925
- **Latest Release Year:** 2021
- **Total Locations:** 750

##  Dashboard Features
1. **Genres by Total Titles** – Displays the distribution of Netflix content across different genres.
2. **Movies vs TV Shows** – Compares the number and percentage of movies and TV shows.
3. **Ratings by Total Titles** – Analyzes content based on ratings such as TV-MA, TV-14, and TV-PG.
4. **Top 10 Countries** – Highlights countries with the highest number of Netflix movies and TV shows.
5. **Release Year Trends** – Shows how the number of movies and TV shows varies across release years.

##  Key Insights
- Netflix's catalog contains approximately **69.6% movies** and **30.4% TV shows**.
- Movies account for approximately **6,130 titles**, while TV shows account for approximately **2,680 titles**.
- **TV-MA** is the most common content rating, followed by TV-14.
- The **United States** has the highest number of titles, followed by India.
- The number of titles increased significantly in recent release years, especially during the 2010s.
- International dramas and documentaries are among the most represented genre categories.

##  Project Objective
- Analyze Netflix content distribution.
- Identify popular genres and ratings.
- Compare movies and TV shows.
- Explore country-wise content availability.
- Understand release-year trends.
- Present meaningful insights using Power BI visualizations.


##  Conclusion
The Netflix Power BI Dashboard provides a clear overview of Netflix's movies and TV shows. It helps identify content trends, genre distributions, ratings, and country-wise contributions through interactive visualizations.

This project demonstrates skills in **data analysis, data visualization, Power BI, Power Query, and dashboard development**.
